# 深压：地下工程经营

Unity 2022.3.62f3c1 / URP 2D。验收场景：`Assets/DeepPressure/Scenes/DeepPressureSurvival.unity`；已有 `DeepPressureColony 15` 等场景进入 Play 也会应用视觉兼容修复，无需重新生成地图。本轮没有覆盖已有EXE。

## v0.9 设备生产与界面

- 底部建造是一个独立格子，已删除v0.8额外的一整排常用设施。
- C / 生产进入设备目录；从实际合成台选择其配方，查看原料与产物、批次和本台队列。工人必须取料并到指定台加工；关机不换台，拆台取消并退还预留。
- 补齐面板开关、按钮、配方、生产进度和完成状态反馈，统一滚动条、界面与世界色彩；打印舱不再过亮。
- NPC保留原目标改道，绕路不反复取料，同等偏好时按真实路线就近认领。没有加入危险避让或自动撤离。

## v0.8 生存与交互修复

- 初始直接运行；倍速按 1→2→4→6→1 循环，数字 1/2/3/4 可直达。
- 底部常用建造直接放置，制造、库存替代独立取样、勘探入口；探索随人员视野进行。
- CO₂受限的藻类回氧、当地氧分压/CO₂反馈与较温和耗氧；参数统一在 `Assets/DeepPressure/Resources/DeepSimulationTuning.asset` 调整。
- 高压气洞无事前探测、无开挖预警，凿穿可造成致命冲击；允许人员进入危险空气。
- 连续雾边、单体仓库、真实机器工作动效、稳定人物重叠排序、新生姿态归正；梯子承重点、向下续建、台阶/跨沟寻路与途中存档恢复。

详见 [本轮说明与调参](docs/生存与交互修复-v0.8.md)。自动验收入口：深压 → 验证 → 生存与交互 v0.8 验收。

## v0.7 生存开局

- 三名人员、一个打印舱、天然洞穴和少量原料；制氧、研究、制造与电力设施需要自行建设。
- 打印舱定期提供三名候选或物资；人口增加会提高实际氧气消耗。
- 缺氧耗尽呼吸储备后损失生命，死亡停止工作与呼吸，人员增减和生命状态支持存档。
- 标题与菜单去掉无关说明；氧气供需与人员状态集中显示（v0.8 开局已改为直接运行）。

## v0.6 已实现

- 有限燃料发电、实际电线施工与独立回路、电池充放电、断线停机。
- 采集泵、原气罐、调压器、分离器、氧气罐、尾气罐、供气口、排气口和污染回收设备分别承担实际功能。
- 六组分逐格气体扩散和热量传输；人员耗氧、CO₂ 产生、气氛不适反馈；危险工业蒸气可回收为制造原料。
- 高压开挖预警、泄压喷流与人员冲击；满足可燃气、氧气和点火设备条件才发生燃爆。
- 工程员到场取样、首次数据奖励；人员和已知设施自动揭雾，岩壁遮挡视线，探索记忆保留。
- 目标库存制造、可用/预留资源、人员分工与工单优先级。
- 图标科技树、检索与固定详情区；可折叠运行状态和世界内故障反馈。
- 按可见底脚修复机器与家具；人物新增待机细节、搬运、攀爬帧，配套法线和 AO；机器动作跟随实际工作状态。
- 主菜单、手动/快速/自动存档、完整气体场/线网/任务恢复、校验与备份恢复。

## 常用操作

B 建造；G 框选挖掘；E 铺线；Shift+E 拆线；J 人员；R 科技；C 制造；I 库存。左键选择人物、右键地点派遣。空格暂停；1/2/3 调速；F5 快存；F9 档案；Esc 逐级返回。

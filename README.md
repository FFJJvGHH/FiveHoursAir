# 深压：可操作经营原型

Unity 2022.3.62f3c1 / Universal 2D / URP 14。

当前入口：Assets/DeepPressure/Scenes/DeepPressureColony 2.unity（Build Settings 已指向该场景）。旧关卡保留。Play 从主菜单进入工程。

## v0.4 交互与流程

- 主菜单、继续最近存档、新工程、3 个手动档位、快速档、120 秒自动档；保存实际世界、工单、材料预留、人物、科技、探索和气网状态，并使用完整性校验与上一版备份。
- 底部图标附常驻中文标签。B 建造、G 框选挖掘、J 人员、R 科技、C 制造、F5 快存、F9 档案；Esc 逐级返回并打开暂停菜单。
- 人员工种偏好/禁用、1–9 工单优先级、停止待命与恢复、右键指定移动；蓝图在完工前不阻挡行走，待建支撑与不可达计划会等待条件恢复。
- 三分支九项科技、15 项建筑、7 条配方；科技节点显示前置连线、实际解锁与材料/供电等条件。工程目标给出下一步入口。
- 八邻域 47 种地形边缘 × 3 变体；灯具根对象统一管理外观、光源、选择和存档。新增岩层材质边界扰动。

操作与来源见 [交互与经营流程-v0.4](docs/交互与经营流程-v0.4.md)。本轮验收状态见 [交互版本验证-v0.4](docs/交互版本验证-v0.4.md)。用户停止桌面操作后未继续操作 Unity；最后的存档往返与界面验收尚未执行，已迁移的编辑器场景尚需保存。

## 可以实际做什么

- 点击底部“建造”图标，选择建筑、查看成本和占格预览，在已探明空地点击提交工单；材料先预留，工人先到仓库取料，再搬到施工地点，作业完成后才出现建筑。工单可取消退款。
- 点击工程员可查看任务，右键可达地面下达移动；人物遵守地面、连续梯子和两格净空。三名工程员拥有原创 Blender 形象、待机/行走/工作帧及逐帧法线、AO。
- 点击合成台，打开制造，选择配方和数量。三条配方：3 矿石→1 合金；2 合金→1 电子元件；1 电子元件→2 研究数据。工人取料并到台操作，成品占用有限仓容；仓满保留待入库成品。
- 点击仓库查看库存与容量；新增仓库增加容量。库存目前由全基地共享，物料取用有人员搬运过程，但尚无逐仓库过滤和独立堆料运输。
- 在建造大厅建研究台，再从“科技”面板启动研究。地下测量→压力工程→选择分离，按前置、数据、物料和工作时间解锁储罐、调压、分离设备。
- 工作灯是建筑对象，可以选中开关；发电机、工作灯、研究台、合成台及工业机器使用统一供电状态。当前是基地母线总功率模型，尚无逐线电网。
- 气体建筑选中后点击“接管”（分离器分产品和尾气口），再点另一设备，产生付费施工工单；完工形成实际气网连接，交叉不自动连接。
- 挖掘工具提交实际作业。完工清除地形、产生矿物、更新探索边缘与房间拓扑。气体房间重连保留库存，不再每次挖掘重新灌满。
- Esc 打开暂停菜单，统一冻结人员、制造、研究、气网和粒子；可继续、回到起始视角、设置音量或关闭粒子。
- 建造、采矿、命令、开关、取样和研究有实际 Unity ParticleSystem 反馈；工作时持续火花/尘土，人员取料后显示携带箱。

## 第一段操作流程

起始已有仓库、合成台、供电机和工业示范线。建造大厅位于主工艺舱左侧，地面坐标 y=53，可在约 (11,53) 建研究台。先完成地下测量，再建新气罐并提交接管工单。通过制造补充材料和研究数据，向下挖掘并用梯子拓展工作面。

地图为 128×80（10,240 格），增加旧矿井、湿气盆地、埋藏工坊、深层气藏和上部裂隙。相机从基地开始，可拖动和缩放，不会开局公开全部地图。

## 编辑者入口

“深压 → 内容编辑器”以物品、建筑、科技和配方为主。规则资产在 Assets/DeepPressure/Data/Gameplay，预制体在其 Prefabs 下。建筑定义管理占格、端口、成本、科技、工时与供电；运行界面直接读取同一目录，不另维护硬编码表。

关卡定义为 Assets/DeepPressure/Data/DeepStation.asset；地层和洞室在生成后仍可逐格/逐物体编辑。原地形工作台保留为辅助工具。

## 验证与边界

“深压 → 验证 → 经营闭环验收”（Ctrl+Shift+F11）在编辑模式运行。7 组气网/地图/探索自检、6 组经营自检以及真实关卡克隆的施工—合成—研究—灯开关—暂停流程已实际执行通过，记录在上级 outputs/colony-validation.txt。

已落实的是上述经营闭环，不是策划案的全部系统。完整食物/睡眠/情绪/技能差异、液体与固体管网、燃烧反应、温度能量、冷凝、复杂机械物流和真实高压破坏尚未实现。环境气体仍采用连通房间的混合库存模型；取样/揭雾是仪器命令，不是完整人物勘探动画。法线是本项目的 Blender HD2D 管线选择，不据此声称《缺氧》使用同一实现。

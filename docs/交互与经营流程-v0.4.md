# 深压：交互、流程与存档重构

本次用户要求作为实施范围。用户附件《深压-核心构建调研与设计-v0.1.md》作为设计背景阅读，其中的阶段设想不当作额外执行指令。

## 参考核查

实际查阅 Klei 官方游戏介绍、官方更新及官方截图入口，没有声称在本机运行《缺氧》。参考的是玩家如何理解并管理殖民地，而不是复制其美术或全部模拟规则。

- [Klei 游戏介绍与实机截图](https://www.klei.com/games/oxygen-not-included)：地下殖民、生存与系统经营构成一体。采用明确的工程阶段与资源循环。
- [Klei Occupational Upgrade 官方公告](https://store.steampowered.com/news/posts/?appids=457140&enddate=1524167439)：人员分工、任务类型与专业化是可见的管理操作。深压提供人员偏好、禁用工作、任务优先级、停止待命及指定移动。
- [Klei Ranching Upgrade 官方公告记录](https://store.steampowered.com/news/posts/?appids=457140&enddate=1521739129)：优先级与紧急度作为显式系统呈现。历史公告说明设计演变，不当作当前所有版本的精确算法。深压自行定义为人员偏好优先、同偏好按 1–9 紧急度、再考虑距离。
- [Klei Expressive Upgrade 官方公告](https://store.steampowered.com/news/posts/?appids=457140&enddate=1536257090&feed=steam_community_announcements)：动作反馈应让玩家理解人物行为。深压保留已有走路、作业、搬箱动画，并补上显式工单进度、区域预览、操作提示与确认音。

## 进入与离开基地

Play 首先显示主菜单，模拟暂停。可开始新工程、继续最近有效存档、选择档案，或查看操作说明。游戏内 Esc 先取消当前工具，再关闭面板/选择，最后打开暂停菜单。暂停菜单提供保存、读取、设置、保存并返回主菜单、返回基地镜头。

保存恢复真实状态：地形与探索、库存及预留材料、建筑开关、科技、人员分工与位置、正在执行的工单、气体库存与连接、相机及模拟速度。手动 3 档，另有快速档和自动档；自动档每 120 秒实际运行时间保存。采用版本与校验、临时文件、上一份备份；损坏主文件可从备份恢复。保存失败在界面反馈，不能默默丢进度。

建筑点击后显示整个物体的状态；灯光是工作灯物体的子组件。编辑器选择根物体即可整体移动、复制或删除灯具与光源。全局环境光仍属于场景环境。

## 前半程工程目标

1. 在建造大厅建设研究台；预留材料 → 仓库取料 → 到达施工点 → 完工。
2. 研究地下测量。用现成合成台形成矿石 → 合金 → 电子元件 → 研究数据循环。
3. 发展压力工程，建造调压器和储气设备，显式连接气体端口。
4. 发展材料制造以满足选择分离的前置条件；分别安排产品与尾气出口。
5. 继续取样、勘探、开挖、梯道施工，按需求拓展电力、仓储和制造。

科技按气体工程、殖民工程、材料制造分支组织，节点显示前置连线、材料、工时、解锁设施/配方、当前缺失条件与研究进度。锁定建筑可直接定位所属科技。

## 地形与对象

逻辑仍按格寻路和建设。视觉按八邻域、47 种有效边缘掩码、每种 3 个变体呈现，挖掘同时刷新对角邻居。裸露面采用侵蚀轮廓、外角圆化和内角缺口；人工楼板保留明确的工程直边。颜色、法线与 AO 对齐。

## 明确边界

这轮完善基础经营操作和可保存的闭环，不等同完整《缺氧》。仍未实现完整饮食、睡眠、情绪、技能成长、逐线电网、液体物流、热力学相变或岩体塌方。供电仍是基地总功率模型，环境气体仍按连通房间混合。隔绝勘探目前是仪器权限，不代表工人生命支持模拟。

验证以本轮实际生成的 outputs 报告及 Game 视图为准，旧轮次文档中的测试结论不替代本次验收。

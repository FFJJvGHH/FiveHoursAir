# 深压：关卡制作流程

这是 Unity 2022.3.62f3c1 / URP 14 的首轮可编辑原型，不是完整经营游戏。工程中不使用运行时随机地图生成。地图布局保存在 `.unity` 场景；运行期只更新工业库存、探索记录、渲染遮罩和界面。

## 1. 打开与生成

在 Unity 打开本工程，等待编译完成。上方菜单 **深压 → 一键生成可编辑示范关卡**（Ctrl+Shift+F7），生成 64×36 固定示范地图。菜单 **深压 → 关卡工作台** 打开统一制作面板。Scene 的 Overlays 菜单还能启用 **Deep Pressure · 关卡工具**，可拖到 Scene 上边缘。

首次输出 `Assets/DeepPressure/Scenes/DeepPressureDemo.unity`。再次生成使用 Unity 唯一路径，不覆盖手工编辑的旧场景。切换场景前采用 Unity 原生未保存修改提示。普通保存用 Ctrl+S。

## 2. 地形

工作台选择 World，选 Soil / Sandstone / Shale / Basalt / Metal；启用 Scene 画笔后左键绘制，Shift+左键擦除，Alt 导航。支持 1–5 格笔刷和 Undo。也可把 `Assets/DeepPressure/Data/Terrain` 的 Tile 资源拖入 Tile Palette 绘制。

`Terrain` Tilemap 是实体地形的权威来源。点击“同步地形 / 重算房间 / 校验”将绘制结果同步到网格；进入 Play 前也会同步。Background、sprite 的透明像素、装饰和贴图颜色不决定占格。

独立素材算法：每块地形查询上、右、下、左同种材质，掩码分别为 1、2、4、8，选择 16 张图片中的一张；绘制/擦除时只刷新自己与四邻格。不同材质边界保留接缝。16 张可直接替换为人工制作的统一规格贴图，算法无需更改。当前是基础程序绘制的模块化占位地块，不是最终前景美术。47-tile 对角形态尚未实现。

每种地形独立保存 densityKgM3、excavationResistance、porosity、permeability。参数为游戏示意值，目前只保存属性，不代表已实现渗流、挖掘或塌方。

## 3. 区域与房间

工作台填写区域名、左下格坐标、宽高，点击添加区域；选中 Region 在 Inspector 编辑 bounds、priority、initialPressureKPa、temperature、composition。composition 顺序 O₂、N₂、CO₂、水蒸气，按摩尔比例归一化。

Region 是作者命名的语义区，不会自动挖空或形成气密边界。重叠区域按 priority 高者、面积小者、stableId 字典序决定。请保持 stableId 唯一，复制区域后必须换 ID。

Physical Room 由 Empty 格的四邻域洪泛确定；对角不相通，接地图外缘标为开放。它用于解释真实围合，不根据区域框、背景颜色或 Collider2D 触发器推断。当前房间气氛是初始化快照，编辑拓扑重算会重新初始化；尚无运行中环境扩散与门开启守恒。

## 4. 独立设备与显式管线

Hierarchy 的 `04 • Explicit Gas Network` 下每个设备均可独立选中、复制、移动。GasNode 编辑容积、压力、成分、承压和吞吐。DeepDevicePlacement 保存与贴图尺寸独立的占格尺寸、偏移及端口坐标。

工作台指定起点、终点、输出口后创建连接。只有 GasLink.from / to 引用构成网络；两条管线在画面相交不会连通。Mixed 是混合口；分离器使用 OxygenProduct 与 TailGas 两路。阀门开关、开度与连接的流量上限可在 Inspector 调整；Play 的选中卡也可操作阀门。

当前管路采用有限设备节点库存和压差输送，线条是独立可编辑 LineRenderer 路径，转角配置保存在场景。尚未实现逐格管段库存、桥接施工或管段自动路由。移动设备时端点与邻近折点自动跟随，中间路径保留；仍可在 LineRenderer Positions 手工调整路线。

Blender sprite 的 Color/Normal/AO 各自保存；菜单 **深压 → 素材 → 绑定 Blender 法线与 AO** 将法线与 AO 作为 sprite secondary textures 绑定。`DeepPressure/Sprite-Lit-AO` 使用 `_NormalMap` 和 `_AOMap`；局部 Light2D 开启 Accurate 法线。AO 对底色作适量遮蔽，实时灯光独立计算。

## 5. 探索、光照与气体

Scene 是编辑器全图视图，Game 才应用玩家迷雾。初始只开放安全基地及井道，其余区域按 Unknown → Sampled → Explored 管理；取样记录不等于看见内部建筑。选择未知空间，先取样，再使用探索命令。危险气氛需要隔绝装备；这是仪器/勘探命令原型，并非已完成的人物寻路与任务系统。

远背景使用 ImageGen 岩壁，配轻微相机视差。前景和设备均为独立对象。全局环境光提供基础明度，暖色作业灯、冷色井道和居住舱灯表现空间层次。气体 shader 是经过探索约束的辅助可视化，不等于现实中 O₂/N₂/CO₂ 可见，也不承担成分判定。

## 6. 验证

保存前执行工作台校验；菜单 **深压 → 验证 → 当前关卡与守恒自检** 检查拓扑、区域优先级、四组分库存、容量、反向阀门、支路顺序、分离器出口堵塞。结果输出到工程上级 `outputs/validation.txt`。具体通过状态以该文件和本次验证记录为准。

验收操作：画一面墙观察房间拆分；擦除观察合并；关闭尾气阀观察分离器停机；重新开启恢复；选择未探索洞室确认没有提前显示组成，再取样、探索。最后按 Ctrl+S 保存编辑场景。

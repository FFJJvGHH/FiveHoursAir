# 深压 v0.2 原型运行说明

本轮原型由 **已保存的静态关卡、编辑器创作工具、有限库存工业气网** 构成。运行时不会随机生成地图，不会创建替代设计者摆放的房间和设备。

## 运行与操作

打开由编辑器工具保存的关卡，进入 Play。顶栏可以暂停、切换 1× / 4× 速度、重置气网库存，以及切换 Surface / Gas / Pressure / Regions 视图。单击机器、管线或地形格查看右侧详情；右键或中键拖动平移，滚轮缩放，空格暂停。机器详情上的 IN / OUT 按钮可开关对应管线，单击管线还可调整 0–100% 阀门。

`RESET GAS` 只恢复工业容器的初始气体与仿真时间，保留刚调整的阀门和开关状态。需要恢复阀门请退出 Play 后重新进入。编辑器里的场景数据不会因本轮 Play 中的操作被保存。

右下角报告仿真时间与四组分独立守恒检查；总库存可从编辑器或 `TotalInventory()` 调试接口读取，不在探索界面公开未知设备库存。气源有限，受压差、调压器设定点、流量和出口容量限制，因此运行一段时间后可能停止流动。

迷雾中的格子不会显示地质、设备、区域名称或房间全局统计。选中未知格后使用 `TAKE SAMPLE` 取得边界样本，再使用 `EXPLORE` 尝试探索。右侧显示保存的样本记录，不把区域初值冒充实时传感器。可见房间若仍延伸到未知空间，其完整房间统计继续隐藏。左下 `GAS FX` 按钮可开关程序化气体视觉层，`SEALED DRONE` 是原型隔离防护开关，允许已采样的危险区域通过防护检查；它不表示已实现人物、无人机实体、装备制作或成本经济系统。

## 本轮实际运行的系统

- 地图以 `DeepTerrainTile` Tilemap 为编辑来源；`DeepPressureWorld.SyncTerrainFromTilemap()` 把已画的格子同步到 `TerrainKind[]`。前景地形决定阻挡，背景 Tilemap 与装饰不参与气室判定。
- 格坐标的原点是 World 物体的局部 `(0, 0)`。格心为 `(x+0.5, y+0.5) * cellSize`；负坐标按向下取整处理。World 根应保持单位缩放，地形 Grid 与此原点、格大小一致。
- `DeepPressureRegion` 是稳定 ID、矩形格范围、优先级和初始大气的语义标签。重叠按 **优先级高 → 面积小 → stableId 字典序小** 决胜。区域边框不阻气。
- `RebuildRooms()` 对 Empty 格四邻域洪泛。斜角不连通，任何触及地图外边界的连通空间标为 Open。房间体积由格面积和横剖面厚度计算；初始各气体摩尔数逐格求和，温度按摩尔数加权，压力由总摩尔数重新计算。
- `GasNode` 容器储存 O2、N2、CO2、H2O 蒸汽四种有限摩尔量；单位关系为 `P(kPa) = n × 8.314462618 × T(K) / V(m³) / 1000`。比例是摩尔比，不是质量比。
- `GasLink` 只认显式 `from` / `to` 引用，管线图像交叉不会自动连接。默认单向止回；普通储罐之间的 Mixed 管线可以显式启用 `allowReverse`，按压差反向流动。调压、分离接口不允许反向。
- 调压器将接收压力限制在 `min(targetPressureKPa, maxPressureKPa)`。每个容器有总吞吐上限，管道还有独立导通系数、最大流量及阀门比例。
- 理想分离器有 OxygenProduct 和 TailGas 两个出口。氧气出口只搬运 O2，尾气搬运剩余三种组分；任一出口关闭、缺失或满载则整机联锁停止，并显示原因。
- 每个固定步先读取全部库存快照，生成各管线请求，再统一限幅和提交。同一来源不会因遍历先后让第一条支路抢走库存；每个组分都独立检查守恒和非负性。

## 明确未实现

房间视图显示 **初始化后的静态大气快照**。当前工业容器与房间气氛没有自动交换，房间并未逐格扩散、浮力分层、泄压到地图外界。Open 只是拓扑标记。重新调用 `RebuildRooms()` 会按区域初值重置房间统计，所以它不是保持运行期房间气体守恒的改造 API。

气网采用等温、理想气体模型。设备之间没有能量守恒、压缩热、对外换热、电力成本、冷凝、液体管网、化学反应、真实组分相图或超压破坏。H2O 始终作为气相处理。理想分离器没有真实分离功耗、纯度曲线或膜的动力学；这些应按设计文档继续实现。

本轮没有人员移动、排班、任务寻路、生命维持消耗、采掘、建筑施工或实时建造 UI。地质密度用于配置和查询，不等同于已完成岩体力学、渗透或采掘模拟。

## 可执行验证

`DeepPressureSelfTests.RunAll()` 可由编辑器工具菜单或 Unity 批处理入口调用，成功返回七组测试摘要，失败抛出异常。测试创建并销毁自己的临时对象，不修改已创作地图。

1. 四邻域房间、开放边界、实体阻挡、世界格坐标、区域重叠优先级、房间初始摩尔量汇总。
2. 四组分分别守恒、有限源消耗、接收压力容量、长时间步不出现负库存。
3. 调换支路遍历顺序后库存结果一致。
4. 默认单向阀阻止逆流、显式反向选项允许高压向低压流动。
5. 分离氧气纯度、尾气不含氧、满尾气罐与关闭出口导致整机停止。
6. Tilemap 画入地形、擦除后同步、背景层不参与阻挡，重建房间读取实际前景。
7. 未采样不能探索、采样不揭图、安全区探索、高压区防护门槛、隔离装备允许探索、远距离取样限制。

这些自检覆盖当前简化模型的不变量，不代表真实流体精度或完整玩法已经验证。

# 探索与气体表现：首版接入与验收

本版新增 `DeepExploration`、`DeepPressure/GasAtmosphere` 和 `DeepPressure/FogOfWar`。关卡地形仍由编辑器创建并保存；运行时创建的是与格网同尺寸的发现状态、组分和压力显示纹理，默认 64×36 像素，不生成或修改地图。

## 探索状态

`Unknown → Sampled → Explored`。初始只揭开生活区 `(4,24,26,8)`、处理区 `(5,13,31,8)`、竖井 `(31,4,3,27)` 及上方连接段 `(28,26,6,3)`。右侧气藏与左下旧站保留迷雾。初始矩形可以在 Inspector 的 `initialExploredAreas` 修改。

`TrySample(cell, out message)` 找到选中语义区域里距已探索格最近的空格，按曼哈顿距离检查 `drillReachCells`，默认 12。钻孔距离允许穿过岩层；它不是人员行走距离。成功记录该取样点当前物理房间的四组分比例、压力、温度和时间，缺物理房间时才使用作者初始值。样本是局部历史记录，不是全气藏储量或实时全图数据。

取样只改变状态，不揭开区域。`TryExplore(cell, out message)` 必须先取样，并满足当前入口环境的游戏阈值；否则给出压力、氧分压、CO₂ 或温度原因。`hasIsolationEquipment = true` 表示允许本原型的隔绝装备勘探。探索成功揭开语义区域及紧邻、没有其他区域归属的空连接格。

这是可解释的简化勘探指令，没有人员寻路、自动挖洞、装备物资消耗或真实气闸循环。隔绝装备也不会降低气体压力或修改房间成分。游戏阈值只是可调平衡参数，不是现实作业标准。样本用 `TryGetSample` 获取，不要用 Region 初始配置替代记录数据。

## Editor 配置

1. 在关卡根对象增加 `DeepExploration`，把 `world` 指向已有 `DeepPressureWorld`。
2. 创建两个白色矩形 SpriteRenderer，尺寸覆盖整个格网，默认中心 `(32,18)`、宽 64、高 36；以 world 为父对象时使用本地坐标。不要使用裁切后只剩部分区域的 sprite。
3. 气体 overlay 赋 `DeepPressure/GasAtmosphere` 材质，引用到 `gasRenderer`；放在背景之上、人物/机器等主要物体之下或用较低不透明度。
4. 迷雾 overlay 赋 `DeepPressure/FogOfWar` 材质，引用到 `fogRenderer`；其 Sorting Layer 必须位于所有地图实体与世界文字之上。组件将 Order in Layer 设置为 32760；若其他对象使用更高 Sorting Layer，仅提高 Order 仍不够。IMGUI HUD 保持可见。
5. 组件通过 MaterialPropertyBlock 传入 world 变换矩阵、cellSize、格网大小及三张纹理，不改共享材质资源。

迷雾材质的 `_DiscoveryActive` 默认 0，只在运行时由组件设置为 1，避免编辑器中整张作者地图被黑幕盖住。Play 后使用实际发现状态遮挡。

HUD 使用 `IsVisible(cell)` 过滤未知位置的地形、机器、管线与实时数据。未知区域可以下达取样/勘探命令，但不提前暴露区域名称。`IsSampled(region)` 对 Sampled 和 Explored 返回 true；未取样但初始已探索区可能没有样本，调用 `TryGetSample` 判定是否存在。跨未探索空间的物理房间统计也要隐藏，防止从已知格反推整片未知洞室。

## 气体与光照

显示纹理 RGBA 分别保存 O₂、N₂、CO₂、H₂O 摩尔比例；压力纹理 R 保存按 `visualPressureScaleKPa` 归一化的总压，G 表示开放气体格。原型读取现有物理房间均匀混合数据，不冒充逐格扩散或气体分层模拟。

Shader 按世界格坐标取样：氧气偏青、氮气偏蓝灰、CO₂ 偏琥珀、水蒸气偏冷白蓝，压力与污染组分影响观察浓度。低频漂移只用于表现，既不运送气体也不改变气体库存。这些颜色是观测模式，不表示真实无色气体能被肉眼看见。

`_TopLightColor`、`_BottomLightColor`、`_DepthLightStrength` 给不同深度的空气表现增加连续分层色调。它不是物理散射，也不能代替独立设备的 Normal/AO 与 2D Light。设备、管线、地形仍使用自己的材质与光照。未知格不写入气体显示纹理，迷雾 shader 同时保持全遮挡；已取样的迷雾只有很轻的颜色差别，透明度仍为 1。

## 验收方法

1. Play 后确认生活区/处理区/竖井可见；右气藏、左下旧站、内部文字和管道都不可见。退出再进入恢复初始发现状态，本版不持久化探索存档。
2. 点击右气藏，直接探索应提示先取样；取样成功后能看样本，但区域图像仍完全遮挡。
3. 没有隔绝装备时尝试探索高压气藏，应因游戏入口压力阈值被拒绝；启用装备后再探索应成功。
4. 把 `drillReachCells` 改为 1，从处理区取样右气藏应因距离失败；改回 12 后成功。
5. 查询越界坐标、无语义区域的岩石、重复探索，应返回可读提示并且不改变地形或气体库存。
6. 在可见房间修改模拟气体或压力，最多一个刷新间隔后色调/浓度跟随；暂停工业模拟时气体显示纹理保留对应状态。纯视觉漂移动画仍可运行。
7. 测试 world 的平移/缩放后 overlay 仍按世界转换采样；确认迷雾 Sorting Layer 真正覆盖世界文字，HUD 不泄漏未知内容。

编译与 Unity 内画面检查由工程整体验证执行；此文档不以预期验收项冒充已全部通过。当前没有探索存档、逐格扩散、流体热浮力、人员探路或动态地形破坏。

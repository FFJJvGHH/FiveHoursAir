# 生存与交互修复 v0.8

本轮以用户最后确认的玩法方向为准：不提供高压气洞探测或开挖预警，凿穿后按实际压差产生冲击，近处未防护人员可以直接死亡。允许派遣人员进入危险气氛，不自动寻找安全空气、不擅自撤离或更换玩家目标。人员靠近自然揭雾，底栏的独立取样、勘探改为制造、库存。

## 集中调参

在 Unity Project 中选择 `Assets/DeepPressure/Resources/DeepSimulationTuning.asset`，直接在 Inspector 修改；已有场景与新游戏共用此配置，运行中读取。可以把配置复制后通过 session 的配置字段分别调试。

| 参数 | 默认 | 含义 |
| --- | ---: | --- |
| breathingMolPerSecond | 0.07 | 每人每游戏秒耗氧；600秒周期约1.344kg，比现实日均参考高约60% |
| diffusionPerSecond | 2.4 | 相邻格守恒混合，墙体阻断 |
| initialCarbonDioxideFraction | 0.0004 | 初始微量CO₂，以等量氮气替换，不增压，不在读档时重复补充 |
| algaeConversionMolPerSecond | 1.5 | 藻类每秒最大CO₂转化能力；实际受当地CO₂、目标氧分压和培养基限制 |
| cultureCapacityMol | 30 | 每单位培养基可转换的CO₂量 |
| algaeAirReachCells | 3 | 沿相连空格交换气体的范围，不能穿墙 |
| oxygenWarningKPa / minimumOxygenKPa | 19.5 / 16 | 不适与应急呼吸阈值 |
| carbonWarningKPa / carbonImpairmentKPa / carbonDangerKPa | 0.5 / 2 / 4 | CO₂不适、明显减效、急性危险分压 |
| carbonToxicityDamagePerSecond / processVaporDamagePerSecond | 0.6 / 0.8 | CO₂、工业蒸气独立中毒伤害基数，不消耗呼吸储备 |
| pressureExposureDamagePerSecond / oxygenExcessDamagePerSecond | 0.35 / 0.2 | 极端总压、高氧暴露的独立渐进伤害基数 |
| airReserveSeconds / airReserveRecoveryPerSecond | 90 / 4 | 应急储备与安全空气中的恢复速度 |
| pressureShockThresholdKPa / pressureShockDamageScale | 40 / 9 | 冲击阈值与伤害系数；伤害随压差比例平方、距离衰减 |

这些是游戏参数。参考现实的量级和因果关系，但没有模拟完整人体生理、光照生物反应器、营养、水与生物质库存。藻类转换采用一摩尔CO₂换一摩尔O₂，培养基提供有限转化预算。CO₂供应不足时停产，不凭空增加氧气。密闭的人物—藻类循环稳定后，供需差接近零是正常结果。只有人物头部所在格的氧分压不足才消耗呼吸储备并导致缺氧窒息；氮气或未点燃的甲烷不会因为“混有其他气体”直接导致窒息。过量CO₂、工业蒸气、过高氧分压、极端气压各自使用明确的渐进伤害和死亡原因，伤害速率可在配置中独立调节或设零。

## 操作与表现

- 新基地直接以1×运行。倍速按钮循环1×、2×、4×、6×；数字1/2/3/4分别直达，空格单独暂停。6×可存档、读档。
- 底部新增常用建造栏：梯子、地板、制氧器、仓库、合成台、研究台和发电机；完整目录由显眼的“建造 B”进入。
- 所有通过共用点击入口的控件获得约140ms悬停反馈与180ms点击反馈，包含分类、工单优先级、开关和存档项；面板短距离进入，命中区域不随点击缩放。
- 雾边从未知格的矩形边界计算连续距离，取消格界的透明度跳变；未知区域仍完全遮挡。
- 仓库删除生成器额外创建的 `Stacked bin` 子物体。保留真实单箱贴图。
- Color按sRGB、Normal按NormalMap、AO按线性灰度处理，作为sprite secondary textures对齐；共享材质保留实际法线和AO，降低过重AO并统一色调。
- 合成台与研究台根据真实工作订单显示动作；风扇、仪表、屏幕和制氧气泡根据实际工作或气体转移更新。停机、堵塞、缺料和暂停不伪装成运行。
- 新生人物重置尸体模板的姿态；人物整体排序避免重叠部件交错。导航增加单格台阶、跨一格沟、梯子斜向登降，向下施工能利用已完成梯段；梯链必须连接实体承重点。

## 参考与 skill 筛选

- [NASA 人体代谢基线](https://ntrs.nasa.gov/citations/20100040625)：用于耗氧量级参考，不按现实一天的时长直接运行。
- [NASA 藻类生命支持研究](https://ntrs.nasa.gov/citations/20170011105)：参考消耗CO₂、释放O₂的因果关系。
- [CDC CO₂暴露资料](https://www.cdc.gov/niosh/idlh/124389.html)：区分低浓度长期暴露与高浓度急性危险，游戏中的阈值和损伤时间仍可调。
- [Component Animation Guidelines skill](https://github.com/konstantinruge/agent-skills/blob/main/skills/component-animation-guidelines/SKILL.md)：参考短促微反馈、统一时长、可中断和保持操作位置；本轮阅读并应用设计原则，未安装或执行第三方脚本。
- [Unity 官方 IMGUI skill](https://github.com/Unity-Technologies/skills/blob/main/skills/ui-imgui/SKILL.md)：确认当前OnGUI实现的维护原则；它主要面向编辑器工具，不把它当成游戏UI架构建议，不为本次修复迁移整套框架。
- [终末地官方研发通讯](https://endfield.hypergryph.com/news/7235)：参考减少工业操作层级、便于连续部署的方向。本轮实现常用直接入口，不声称复刻完整蓝图、物流或集成工业系统。
- [Klei《缺氧》](https://www.klei.com/games/oxygen-not-included)：作为殖民人员、挖掘、气体与基地管理的设计参考；没有证据说明本项目原来的取样流程是《缺氧》的必要机制，因此按用户最新意见移除独立入口。

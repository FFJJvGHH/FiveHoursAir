## 未完成的验证与排除项

本轮没有启动《缺氧》《Stationeers》或《异星工厂》做对照实验，没有声称审计这些游戏的源码。v0.1 对《缺氧》单元素格、离散管包、管桥优先级的描述原先基于社区 wiki；本轮没有新增一手证据，因此正文只记录其证据等级，不将其作为本项目的强制规则。

检索过程中出现的论坛玩家求助、Reddit、Wiki 和第三方教程未作为 v0.2 的技术结论依据。Blender 英文 `render/cycles/baking.html` 与 `render/layers/passes.html` 的直接抓取失败；官方其他语言的手册索引提供了烘焙能力说明，实际输出仍必须在 Unity 中验证。

本项目的四邻接 16 掩码、47-tile 扩展、区域 flood-fill、任务排序、守恒更新、高压处理链与多贴图规范都是我方设计，不声称来自参考游戏的原始实现，也不意味着已在本轮全部开发完成。

# 素材接触关系与角色表现 v0.6

本轮依据 [create-game-assets](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/main/skills/disciplines/create-game-assets/SKILL.md) 的素材家族、可见底脚、稳定帧基线和实际尺寸检查方法实现。Unity 2D 参考仅作为渲染与导入方法参考，项目仍使用 Unity 2022.3 API。

## 实际资源与实现

- `DeepPresentationUpgrade` 读取每张源图 alpha ≥ 26 的可见边界。落地建筑按可见物体整体适配占格，再把底脚对齐到根对象上方 0.003 格。新建筑 prefab、现有实例和旧式 GasNode 设备都有对应迁移；根对象、占地语义与法线/AO 贴图不通过改动 PNG 来补偿。
- 附属面板、转子、仪表与壳体一起变换。灯具使用明确的顶板/壁板安装支架，不能当作地面机器下移。物体拥有接触阴影，改变比例后不会留下独立漂浮附件。
- 实机检查发现旧场景的装饰植物槽和控制台也带有底脚空隙。补充迁移只匹配 Props 下的床铺、植物槽、控制台和箱子，并排除建筑/人物/气体节点内部附件；以附近真实地块表面为接触面。每件家具和其接触阴影属于同一个 `DeepFurnishingMount` 选择根对象。不会移动整个装饰分组或把壁挂设施拉到地面。
- `DeepWorkerPresentation` 根据实际位移推进步态；竖向移动使用攀爬帧，带物料使用搬运帧。工作时朝向目标。待机有不同节奏的呼吸、视线偏转和眨眼，暂停冻结所有动作；帧切换和呼吸保持可见靴底基线。
- 12 个新增姿势（4 待机细节、4 搬运、4 攀爬）各含 Color、Normal、AO，共 36 张 256×256 贴图。通过本项目原有 `ArtSource/Blender/survey_engineer.blend` 渲染，未使用或提取《缺氧》角色资源。原图、摄像机、色板和模型家族保持一致。
- 可重建源脚本：`Tools/Blender/build_worker_detail_frames.py`。此脚本调用 Blender 原生渲染，不对已有位图进行绘制修改。新增图与既有图采用同一 PPU 和图幅，Normal/AO 由导入迁移绑定。
- `DeepMachineMotion` 保持机壳与底脚固定，只驱动仪表和转子。转速由实际订单、气流及发电状态决定，停机缓停，故障慢闪。电池前方三段刻度由实际储能决定；供氧/废气/吸气/净化设备有对应服务色带。
- `DeepSemanticIcons` 独立绘制 64px 几何符号供 24–32px UI 使用。科技和建造按钮无需缩小带大量透明留白的场景图片，建筑定义中的原始美术图仍可用于创建 prefab。

## 验证接口

在停止 Play 后调用 `DeepPresentationUpgrade.ApplyToCatalogAndLoadedScenes(catalog)`，然后保存场景。`ValidateCatalogGrounding(catalog)` 检查所有落地 prefab 的可见底脚偏差不超过 0.02 格，并检查每个角色姿势在呼吸缩放范围内具有同一靴底基线；不通过时抛出异常。

可见尺寸和动效仍需要在 Game 视图中核查，尤其是角色上下梯、带物料停步以及发电机关停。不能把资源渲染成功或 C# 编译通过当作这些实机行为的验收结果。
